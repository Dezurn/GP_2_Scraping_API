### Использованные библиотеки:
- `requests` — для отправки HTTP-запросов и получения данных по API и отдельным страницам вакансий;
- `selenium` — для загрузки страниц со списком вакансий и извлечения ссылок на вакансии;
- `BeautifulSoup4 (bs4)` — для извлечения структурированных данных из HTML-разметки;
- `pandas` — для формирования и сохранения итоговых датасетов, а также их анализа;
- `logging` — для логирования этапов сбора данных и возможных ошибок.

### 1. Superjob API
Для запросов к `API SuperJob` были использованы следующие запросы:

Запрос к списку городов для определения `id` нужного города (в нашем случае `Москва`, `Екатеринбург` и `Санкт-Петербург`);

Запрос к списку регионов для определения `id` нужного региона (в нашем случае это была `Московская область`);

Запрос к списку вакансий для определения `id` соответствующих параметрам вакансий (`регион`, `город`, `категория`);

Запрос к вакансии для получения и дальнейшего извлечения информации о вакансии;

Запрос к списку метро для конкретного города для получения названия `линии метро` и `цвета линии метро`;

Запрос к списку компаний для получения информации по конкретной компании для соответствующей вакансии.

### По результатам проведения данных запросов и извлечения информации из них был получен датасет superjob_all.csv, содержащий следующие признаки:

`id` — уникальный идентификатор вакансии в API SuperJob (число)

`Название вакансии` — наименование профессии, на которую компания ведет поиск (строка)

`Минимальная зарплата` — нижняя граница зарплаты (число)

`Максимальная зарплата` — верхняя граница зарплаты (число)

`Валюта` — денежная единица, в которой будет выдаваться зарплата (строка)

`Категория` — сфера, к которой относится вакансия (список строк)

`Детальные категории` — более узкая сфера, к которой относится вакансия (список строк)

`Город `— город, в котором размещена вакансия (строка)

`Метро` — станция метро, на которой размещена вакансия (список строк)

`Линия метро` — название линии метро, на которой размещена вакансия (список строк)

`Цвет линии метро` — цвет линии метро, на которой размещена вакансия (список строк)

`Адрес` — текстовый адрес места работы (строка)

`Id компании` — уникальный идентификатор компании, которая разместила вакансию, в API SuperJob (число)

`Индустрия` — сфера работы компании (список строк)

`Кол-во персонала в компании` — количество человек, работающих в компании (строка)

`Кол-во размещенных вакансий` — количество размещенных вакансий компанией (число)

`Название компании` — наименование компании, которая разместила вакансию (строка)

`Опыт` — требуемый опыт работы кандидата для вакансии (строка)

`График работы` — формат рабочего графика (строка)

`Образование` — требуемый уровень образования кандидата для вакансии (строка)

`Широта` — географическая широта расположения работы (число)

`Долгота` — географическая долгота расположения работы (число)

`Ссылка` — прямая ссылка на вакансию (строка)
